# Domain System Themes 🎨

Catálogo oficial e repositório de temas para o ecossistema **Domain System (CockPit OS)**.

## 📦 Temas Oficiais

| Tema | Versão | Descrição |
| :--- | :--- | :--- |
| **rachidd_store** | `v1.0.0` | Tema Oficial RachidD.com estilo AliExpress / Marketplace das Mil e Uma Noites (vitrine dropshipping de alta conversão). |

## 🛠️ Comandos de Manutenção

### Empacotar Temas e Atualizar Catálogo
```bash
php tools/build-themes.php
```

### Sincronizar Tema do Core
```bash
php tools/sync-theme.php rachidd_store
```
